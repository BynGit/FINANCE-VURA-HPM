# FinanzApp 💰

Aplicativo móvil Android desarrollado con **Jetpack Compose**, cuyo propósito es exponer contenido informativo y educativo que ayude a las personas a comprender y optimizar sus finanzas personales.

## 📌 Objetivo general

Desarrollar un aplicativo móvil con Jetpack Compose en Android Studio para exponer diferente material y contenido que permita informar y optimizar las finanzas de las personas.

## 🎯 Objetivos específicos

- Identificar las principales necesidades de información y dificultades financieras de los usuarios.
- Diseñar la arquitectura de información y la interfaz del aplicativo móvil.
- Desarrollar los módulos funcionales que permitan la publicación, organización y consulta del contenido.
- Evaluar el funcionamiento y la utilidad del aplicativo mediante pruebas con usuarios.

## 📝 Justificación

Este proyecto se justifica por la necesidad de brindar a los usuarios una herramienta accesible que exponga contenido educativo sobre finanzas personales, contribuyendo a mejorar su comprensión y toma de decisiones económicas, apoyada en tecnologías como Jetpack Compose, Kotlin y Android Studio que garantizan un desarrollo moderno, funcional y escalable del aplicativo.

## 🛠️ Tecnologías utilizadas

| Herramienta | Descripción |
|---|---|
| **Jetpack Compose** | Framework moderno de Google para construir interfaces de usuario nativas en Android de forma declarativa. |
| **Java - Kotlin** | Lenguajes de programación soportados oficialmente para el desarrollo Android; Kotlin es el lenguaje principal. |
| **Android Studio** | Entorno de desarrollo integrado (IDE) oficial para aplicaciones Android. |
| **Git - GitHub** | Sistema de control de versiones y plataforma de alojamiento remoto para el trabajo colaborativo. |

## 📱 Funcionalidades principales

La aplicación cuenta con un **menú lateral** que permite navegar entre las siguientes secciones:

| Sección | Descripción |
|---|---|
| **Perfil** | Muestra el perfil del usuario (foto, información financiera resumen, metas de ahorro). |
| **Gráficos** | Lista de infografías/imágenes con scroll, cada una con su descripción. |
| **Video** | Reproduce contenido educativo en video, con controles de reproducción. |
| **Web** | Permite cargar una página web ingresando su URL en una caja de texto. |
| **Acciones** | Ejemplos de botones e interacciones (descargar reporte, simular ahorro, contactar asesor, editar perfil). |

## ✅ Requerimientos funcionales

- RF01: Mostrar un menú lateral con las opciones de navegación disponibles.
- RF02: Mostrar la sección de Perfil con datos del usuario y scroll para campos de texto.
- RF03: Mostrar la sección de Gráficos con lista de imágenes desplazable y su descripción.
- RF04: Mostrar la sección de Video con controles de reproducción.
- RF05: Mostrar la sección Web, permitiendo ingresar y cargar una URL.
- RF06: Mostrar la sección de Acciones con ejemplos de botones.
- RF07: Permitir la navegación entre secciones sin cerrar la aplicación.

## ⚙️ Requerimientos no funcionales

- RNF01: Compatibilidad con dispositivos Android desde una versión mínima definida.
- RNF02: Interfaz desarrollada con Jetpack Compose, con navegación fluida.
- RNF03: Tiempo de carga reducido en cada sección.
- RNF04: Interfaz intuitiva y de fácil uso.
- RNF05: Buenas prácticas de desarrollo y control de versiones con Git/GitHub.
- RNF06: Estabilidad de la aplicación durante el uso.
- RNF07: Consistencia visual (colores, tipografía, iconografía) en todas las secciones.
